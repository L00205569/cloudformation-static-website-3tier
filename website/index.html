Welcome to the Three-Tier Message Board

A modern cloud application built with AWS

Share a message and see it stored in a MySQL database on Amazon RDS. A Flask API running on Amazon EC2 handles requests, while Amazon S3 and CloudFront deliver the website to users.

⌘ Application Architecture

The application runs in a custom Amazon VPC with public and private subnets.

☁ Amazon VPC — Networking Layer

🌐 Users Web browser
🌍 CloudFront Content delivery
🪣 Amazon S3 Static website
Users → CloudFront → S3 for website files

Amazon VPC: Application and database network

🖥️ Public Subnet Amazon EC2 · Flask API
🗄️ Private Subnets A & B Amazon RDS · MySQL
CloudFront /api requests → EC2 → RDS
⇅   Internet Gateway (VPC internet connectivity)

The RDS database is placed in private subnets. The Internet Gateway provides a VPC route to the internet; it does not make private database subnets directly public.
